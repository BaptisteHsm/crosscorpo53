Gestion des Cross Corporatifs 53 et affichage des résultats, classements de la saison, statistiques et analyses de parcours.

== Installation ==
1. Extensions › Ajouter › Téléverser une extension : choisir cc53-resultats.zip, puis Activer.
   À la première activation, les cross de la saison 2026-2027 et les résultats déjà publiés sont créés.
2. Créer une page « Résultats » et y insérer le shortcode [cc53_resultats] (bloc « Code court »).

== Utilisation ==
Menu « Cross Corpo » :
* Tous les cross / Ajouter un cross : numéro, date, lieu, page « En savoir plus », organisateurs (nom + logo), lieu de départ, parkings.
* Dans la fiche d'un cross : « Choisir le PDF « Scratch » » pour publier les résultats, « Choisir un GPX » pour les tracés long et court.
* Réglages : saison, heures de départ, dossards masqués (droit d'opposition), contact pour les données personnelles.

Le PDF est lu dans le navigateur de l'administrateur : seuls les classements sont enregistrés, l'année de naissance est remplacée par une tranche d'âge et le PDF n'est pas conservé.
Les données sont stockées dans wp-content/uploads/cc53/. Aucun service externe n'est nécessaire, à l'exception des fonds de carte (OpenFreeMap, Esri, Mapzen/AWS) affichés dans les pages « Analyse » et « Revivre la course ».
