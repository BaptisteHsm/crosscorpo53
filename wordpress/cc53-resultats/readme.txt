Résultats, classement de la saison, statistiques et analyse des parcours des Cross Corporatifs 53.

== Installation ==
1. Extensions › Ajouter › Téléverser une extension : choisir cc53-resultats.zip, puis Activer.
2. Créer une page « Résultats » et y insérer le shortcode [cc53_resultats] (bloc « Code court »).
3. Facultatif : Réglages › Cross Corpo 53 pour enregistrer un jeton GitHub et envoyer les PDF « Scratch » depuis WordPress.

== Fonctionnement ==
Les résultats sont lus dans les PDF « Scratch » déposés sur le dépôt GitHub BaptisteHsm/crosscorpo53, puis publiés sur GitHub Pages.
L'extension charge l'application et les données depuis GitHub Pages : chaque nouveau cross apparaît sans mise à jour de l'extension.
Les polices sont servies depuis GitHub Pages (pas de Google Fonts). Aucun cookie n'est déposé.
